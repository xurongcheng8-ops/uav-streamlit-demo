# 面向城市治理的多机巢无人机巡检任务计划排班与动态响应优化研究

本项目是一个可直接运行的 **Python + Streamlit 可视化科研原型系统**，主题为：

> 面向城市治理的多机巢无人机巡检任务计划排班与动态响应优化研究

系统用于大学生创新训练项目、课程设计或科研答辩演示。它不是商业化软件，而是一个用于展示城市治理巡检任务、多机巢无人机位置、任务计划排班、动态响应优化、路径规划、状态监控、调度约束、算法对比和数字孪生验证流程的可交互原型。

## 功能模块


### 1. 总览 Dashboard

- 项目名称与英文副标题展示
- 当前任务总数、已完成任务数、执行中任务数、在线无人机数量等关键指标
- 项目技术路线：
  城市治理任务场景抽象 → 多无人机调度模型构建 → 约束条件建模 → 调度优化算法设计 → 数字孪生仿真验证 → 调度效果可视化评估
- 项目创新点展示
- 调度规则运行摘要与预设演示场景

### 2. 地图态势 Map View

使用 Plotly 构造模拟城市低空坐标系，不依赖真实地图 API Key。

展示内容包括：

- 无人机起降点与换电点
- 河道巡查、火情上报、交通拥堵监测、违停取证、基础设施巡检、应急救援辅助等任务点
- 禁飞区与风险区域
- 无人机当前位置
- 已规划路径与路径重规划结果

### 3. 任务管理 Task Management

任务表格字段包括：

- 任务编号
- 任务类型
- 位置
- 优先级
- 截止时间
- 分配无人机
- 状态
- 响应时间
- 是否准时完成
- 调度提示

系统会对高优先级任务、禁飞区任务点和调度异常进行醒目展示。

### 4. 无人机资源 UAV Resources

展示无人机集群状态，包括：

- 无人机编号
- 电量
- 当前位置
- 载荷能力
- 当前任务
- 剩余航程
- 状态

每架无人机均显示电量进度条，电量低于 20% 时自动触发返航警示。

### 5. 算法对比 Algorithm Comparison

内置四类调度算法对比：

- 传统贪心算法
- 遗传算法
- 强化学习算法
- 改进调度算法

对比指标包括：

- 总任务完成率
- 平均响应时间
- 总飞行距离
- 电量消耗
- 高优先级任务准时率
- 综合评分

通过表格、柱状图和雷达图展示算法对比实验结果，其中“改进调度算法”表现最好，用于体现项目方法优势。

### 6. 数字孪生仿真 Digital Twin Simulation

提供仿真控制台：

- 开始仿真
- 暂停仿真
- 重置仿真
- 生成突发事件
- 切换调度算法
- 选择任务场景

点击“生成突发事件”后，系统会显示：

> 区域 B 出现突发火情，系统已重新分配最近且电量充足的无人机前往处理，并自动避开禁飞区。

## 简化调度逻辑

系统实现了一个可解释的简化调度规则：

- 高优先级任务优先分配
- 优先选择距离任务点最近的无人机
- 电量低于 25% 的无人机不能分配新任务
- 执行火情上报、应急救援辅助等任务时，优先选择带红外相机或多传感器载荷的无人机
- 无人机电量低于 20% 时，状态自动变为返航
- 如果任务点在禁飞区内，系统提示需要路径重规划

## 安装依赖

建议使用 Python 3.9 及以上版本。

```bash
pip install -r requirements.txt
```

## 运行命令

在项目目录下执行：

```bash
streamlit run app.py
```

或：

```bash
python -m streamlit run app.py
```

运行后浏览器会打开本地地址，通常为：

```text
http://localhost:8501
```

## 演示说明

答辩演示时推荐流程：

1. 在“总览 Dashboard”说明项目背景、技术路线与创新点；
2. 在“地图态势 Map View”展示无人机集群、任务点、禁飞区、风险区域和路径重规划；
3. 在“任务管理 Task Management”说明多任务调度与约束校验；
4. 在“无人机资源 UAV Resources”展示电量约束、载荷约束和无人机状态；
5. 在“算法对比 Algorithm Comparison”展示改进调度算法的优势；
6. 在“数字孪生仿真 Digital Twin Simulation”点击“生成突发事件”，演示突发火情下的动态重调度。

## 后续可扩展方向

- 支持任务批量导入、仿真回放与实验报告自动生成；
